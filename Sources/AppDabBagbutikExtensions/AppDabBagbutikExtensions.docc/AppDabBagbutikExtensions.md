# AppDabBagbutikExtensions

@Metadata {
    @TechnologyRoot
}

Use AppDabBagbutikExtensions for display formatting helpers on App Store Connect values provided by Bagbutik.

## Overview

The module adds human readable names for selected App Store version and customer review response states. The values are intended for display; use the original enum values for program logic.

## Topics

### Display names

- ``AppVersionState/prettyName``
- ``CustomerReviewResponseV1/Attributes/State/prettyName``
